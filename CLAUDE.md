# anti-slop

Claude Code plugin that catches agentic-dev shortcomings (security, accessibility, AI-default design, banned vocabulary, regressions). Public repo TheMizeGuy/anti-slop, MIT; the shipped version is whatever the five parity spots say (see Rules below). The dev clone `~/Dev/anti-slop` is the source of truth for development. On this machine the plugin comes from the `mize-plugins` directory marketplace, which loads it straight from `~/Claude/plugins/anti-slop/anti-slop` in every new session (a running session after `/reload-plugins`), not from the versioned plugin cache (verified 2026-10-02 in a debug log). A change is therefore live as soon as that clone pulls it, so pull there only when a change is ready and try work in progress with `claude --plugin-dir ./anti-slop`; no cache sync is needed. Installs from the public marketplace repo are cached by version and change only after `claude plugin update`.

## Layout

- `anti-slop/` — the plugin itself: `skills/anti-slop/` (SKILL.md + 13 references), `agents/slop-detector.md`, `commands/slop-check.md`, `scripts/` (the scanner CLI). No `.mcp.json`: the MCP server was removed in 2.0.0 and the plugin has zero runtime dependencies.
- `.claude-plugin/` at root — marketplace manifests.
- `tools/jev-audit/` at root (2.4.0) — the maintainer-only Jev scoring harness for the plugin's instruction surfaces: `audit.mjs` (six batteries plus the report), `questions.mjs` (the question constants and the `jev-1.13.0` model pin), `pairs.mjs`, `candidates.mjs`, `README.md`. Outside `anti-slop/` on purpose, because everything under `anti-slop/` ships; `out/` and `cache/` are gitignored.
- `anti-slop/scripts/slop-scanner.mjs` — the CLI entry point and the module that re-exports the rule tables (never rename; the command and docs point at this path). Subcommands: `scan`, `history`, `stats`, `dashboard`. Logic lives in `scripts/lib/`: `rules.mjs` (rule data + precompiled regexes), `scan.mjs` (`scanContent`/`calculateScore`/`verdict`/`proseScopeFor`), `store.mjs` (per-project `.anti-slop/` data + `~/.anti-slop/registry.json`; `ANTI_SLOP_REGISTRY_DIR` env override for tests), `stats.mjs` (per-rule active vs suppressed counts), `dashboard.mjs` + `dashboard.html` (on-demand stats dashboard).

## Model policy

- Agent frontmatter carries no model pin. The dispatching session chooses the model per dispatch (global `~/.claude/CLAUDE.md` § Models and agents); effort is never pinned.

## Commands

- Test: `cd anti-slop/scripts && npm test` (the hermetic suite under `scripts/test/`; no deps, no lint/build step — `npm ci` is unnecessary). Use `npm test`, NOT bare `node --test` — Node's bare runner recursively executes the non-test corpus samples under `test/corpus/` and fails on their deliberate missing imports. The script preloads `test/env.mjs` (`--import`), which pins `ANTI_SLOP_PROSE_SCOPE=all` in every worker because the fixtures are prose tells; a by-name run needs the same `--import ./test/env.mjs`, and `prose-scope.test.mjs` clears the variable to test the default.
- Measure scanner precision/recall against the labeled corpus: `npm run measure` (report only) — regenerate `test/corpus/baseline.json` per `test/corpus/README.md` after deliberate rule changes.
- CI scan CLI: `node anti-slop/scripts/slop-scanner.mjs scan [--format text|json] [--fail-on any|high|medium|low|none] [--record] [--quiet] [--prose-scope user-facing|all] <files...>` (exit 0/1/2; no side effects without `--record`).
- Link integrity for the reference library: `npm run check-references` (also gated by `test/references.test.mjs`).
- Dev-run the plugin from a clone: `claude --plugin-dir ./anti-slop` (run from the repo root).

## Rules for this repo

- The scanner's subtle behaviors are deliberate and spec'd by the tests: escape hatch (`anti-slop-allow`/`unslop-ignore`), prose noise-stripping, low-confidence word clustering (count >= 2), design-pattern `suppress`, `skipInTests`, hardcoded-secret precision guards. Never weaken a test to pass.
- Every UI rule declares `confidence` (the four-class enum) and `mode` (presence, or concentration + `minCount`); code rules declare `confidence`. Every table rule also declares a non-empty `fix` of at most 160 characters (2.4.0), and the four inlined families carry theirs as `BANNED_WORD_FIX`, `BANNED_PHRASE_FIX`, `EMDASH_FIX` and `EMOJI_FIX`. `test/rule-metadata.test.mjs` fails on a rule missing any of them, and on any drift between `CONFIDENCE` in rules.mjs and its single definition in `references/confidence-and-evidence.md`.
- Design tells run on web extensions only and native tells on Apple extensions only (`WEB_SURFACE_EXTENSIONS` / `NATIVE_UI_EXTENSIONS`). A rule that fires `text-4xl` on Swift or `.frame(width:` on CSS costs more trust than it earns.
- Emoji is Unicode's definition (`EMOJI_ATOM`: Emoji_Presentation, Extended_Pictographic + U+FE0F, keycaps, flags, ZWJ sequences as one), never a code-point block list: a block list flags text glyphs that code files use routinely, a plain right arrow above all (CHANGELOG.md has the counts). The property escapes resolve against the running Node's Unicode tables, so emoji newer than the interpreter's ICU are not matched (a block list would catch them by range); 97 text-presentation pictographs (⚠ ✔ ❤ ➡ and kin) are text by decision, and a companion tell in the style of `media-control-glyph` is the shape if a subset should come back. The bare media-control glyph used as a control is `media-control-glyph` (design + native, `MEDIA_CONTROL_GLYPH` pushed into both tables; `rule-metadata.test.mjs` pins one object on disjoint surfaces). `eval-usage` refuses `$`/word before the name and skips lines that are entirely a comment (`COMMENT_LINE`: a `/* */` that closes with code after it is code, `*gen() {` is a method); a rule that opts into that suppress is saying its defect cannot live in prose. Content with a NUL byte is binary and matches no rule.
- Prose-scope globs are relative to the directory the scanner runs in (where it reads `.anti-slop/config.json`), case-insensitive, and `globToRegExp` collapses repeated `**/` before compiling (an uncollapsed chain backtracked exponentially). Scope is decided before a file is opened, so a skipped file cannot abort the run; `--quiet` prints the skip hint on stderr only when nothing at all was scanned. The default stays `user-facing` with no shipped default list by decision: an unconfigured project scans no prose, and the command and agent say so rather than calling a skipped README internal.
- Never widen a rule so far that its remediation would remove responsive, accessible, or motion-preference behaviour; narrow the match instead, as `tailwind-hero-triplet` (the verbatim Tailwind run, not any responsive type scale) and the `important-overuse` reduced-motion suppress do. The corpus carries `responsive-type-clean.html` and `AdaptiveShell.swift` as clean controls for that over-widening.
- Dashboard is optional by design: nothing may start an HTTP listener except an explicit `slop-scanner.mjs dashboard` call; `.anti-slop/config.json` `{"dashboard": false}` must keep disabling it. The dashboard shows findings stats only — the /50 score belongs to the `scan` output. `lib/dashboard.mjs` and `lib/stats.mjs` are dynamically imported so the `scan` path never loads the HTTP module. The `dashboard` call serves in the foreground until SIGINT, so the CLI must not reach `process.exit` between printing the URL and SIGINT (the port would then answer nothing); `test/no-mcp.test.mjs` spawns the command, fetches from it, and checks that SIGINT unregisters the project.
- The `slop-detector` agent finds its reference library through `${CLAUDE_PLUGIN_ROOT}/skills/anti-slop/references`, which Claude Code substitutes in agent and skill content (plugins reference, environment variables). A cwd-relative `Glob` cannot see the plugin cache, so a reference lookup routed through the project directory reports the library unreachable in every project except a clone of this repo. Never route the agent's reference lookup through the project directory.
- Version bumps touch 5 spots: SKILL.md frontmatter, both plugin.json files, marketplace.json, and `anti-slop/scripts/package.json` (it ships inside the plugin and prints its version on every `npm run measure`). `test/dashboard.test.mjs` A9 enforces agreement across all five.
- Prose scope (2.3.0): the writing rules cover user-facing prose. `scan.mjs proseScopeFor` skips `.md/.mdx/.txt/.rst` files under the default `user-facing` scope unless `.anti-slop/config.json` lists them under `userFacingProse` (globs: `**`, `*`, `?`) or sets `proseScope: "all"`; `--prose-scope` and `ANTI_SLOP_PROSE_SCOPE` override per run, flag over variable over config. Code surfaces are never affected. The corpus, measure and dogfood paths pass `{ proseScope: "all" }` explicitly; never let the project's own policy default leak into a rule measurement.
- Dogfood before committing docs: scan edited .md files with the project's own `scanContent` and diff finding counts against the pre-edit baseline (`--prose-scope all` on the CLI, or the docs skip). Measure the baseline first rather than trusting a remembered number, and leave untouched prose alone.
- Everything under `anti-slop/` SHIPS. The marketplace `source` is `./anti-slop` and `claude plugin update` copies that directory verbatim into every installer's cache, so a file put there for maintainer convenience is distribution. Maintainer-only material (local paths, private repo names, session or memory-system identifiers, executed work orders) belongs at the repo root or outside the repo; only docs written for a public reader go inside `anti-slop/docs/`. Before a release, grep the SHIPPED subtree (`git ls-files -- anti-slop/`), not just the repo, and note that `git grep -E` silently ignores `\b`, so hygiene patterns need explicit character classes.
- The corpus is the single owner of its fixtures; ui-craft's `tests/corpus/` is a downstream view. Per-item ownership across the three repos is in `anti-slop/docs/rankings-refresh.md` (Downstream sync). Fixture roles are `positive`, `clean-control`, and `coverage-boundary` (plants a real tell this scanner has no rule for -- never cite one as evidence the tell is absent).
- `store.mjs` captures `process.cwd()` at import time; tests needing a different project dir must spawn a child node process (see the allowedWords test).

## Release and maintainer notes

Project notes live in this file. Serena was retired on 2026-10-09; the untracked `.serena/memories/` notes it left repeated this file, apart from the points below.

- Release: the five version spots plus a CHANGELOG entry, focused commits, an annotated tag `vX.Y.Z`, then push `master` and the tag. Regenerate `anti-slop/scripts/package-lock.json` with `npm install --package-lock-only --offline`; never hand-edit it.
- `test/dogfood.test.mjs` pins every shipped `.md` file at zero findings. This file carries one known em-dash-density finding, so measure it before and after an edit rather than expecting zero.
- GitHub push protection scans fixture values: a synthetic secret must not copy a vendor key format (a 24-character `sk_live_` value was rejected in 2.2.2).
- Rankings refresh is quarterly. `anti-slop/docs/rankings-refresh.md` is the runbook, and `empirical-rankings.md` frontmatter carries `last-refreshed` and `next-due`.
